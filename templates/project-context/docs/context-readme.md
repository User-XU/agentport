# Context README

This project uses Portable Agent Context System.

## Agent Startup

Agents should read:

1. `AGENTS.md`, `CLAUDE.md`, or `HERMES.md`
2. `.agent-context/rules/project-rules.md`
3. `.agent-context/memory/PROJECT_MEMORY.md`
4. `.agent-context/logs/LOG.md`

## Memory Evolution

Store only stable, reviewed project facts in `.agent-context/memory/`.
Temporary notes stay in normal work artifacts or drafts.
