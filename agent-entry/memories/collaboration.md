# Collaboration Memory

Use this file for stable collaboration preferences that should follow the user
or team across projects.

## Starter Defaults

- Prefer real local inspection over generic advice.
- Prefer clear decisions after options have been compared.
- Preserve exact paths, names, commands, and error text when they matter.
- Keep updates concise while work is in progress.
- After meaningful changes, say what changed, where, and how it was verified.

## Customize

Add dated notes when preferences become stable enough to guide future agents.
